## 6.7 StandardPlugin vs ResearchPlugin

Show the actual Scala 3 plugin taxonomy:


## 6.8 Why Scala 3 design avoids deeper typer integration

Explain the protocol difference.

Current design:

```text
precompiled marker
+ @expander metadata
+ bounded syntactic/import-aware annotation identity
+ precompiled handler
    |
    v
untpd transformation
    |
    v
ordinary typer performs semantic work once
```

Contrast with Scala 2 Paradise's analyzer-integrated protocol.

Make clear this is a design trade, not a theorem that a different Scala 2 implementation was impossible.
